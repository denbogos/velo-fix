VELO FIX 2.9.1 — восстановление и анализ велотренировок
=====================================================

ЧТО ДЕЛАЕТ
• Открывает FIT с велокомпьютера и записанный GPX (Strava, телефон, часы):
  пропуски GPS в GPX тоже можно дорисовать и сохранить обратно в GPX.
• Исправляет FIT-файл велокомпьютера: ложные километры, «фантомное движение»
  (GPS «едет» 100+ км/ч, пока вы стоите), GPS-телепортации, дубликаты записей,
  нереальную максимальную скорость, выбросы пульса и мощности (статика ремня, сбои
  измерителя). Каденс, высота и время не меняются.
• Достраивает пропуски GPS по GPX с реальным маршрутом (gpx.studio, komoot, телефон)
  или прямо в программе: окно «Дорисовать участок» прокладывает линию по дорогам
  (можно без ПДД — по встречке и тротуарам) и показывает длину против датчика.
• Карта (OpenStreetMap / спутник) с треком, окрашенным по скорости, пульсу или мощности;
  профиль высоты, скорости, пульса и мощности; статистика выделенного отрезка.
• Сводка тренировки «было / стало», зоны пульса и мощности (FTP, NP, Вт/кг).
• Несколько тренировок сразу, склейка частей в одну, сохранение всех в папку.
• Экспорт: FIT для Strava / Garmin, GPX, TCX, PNG-картинка карты, отчёт «до и после»
  (HTML с картами и таблицей — можно приложить к обращению в Strava или отправить тренеру),
  таблица изменений.
• Кнопка «С велокомпьютера»: заезды с подключённого по USB Garmin / Wahoo.
• Обрезка и разделение тренировки (например, если забыли выключить запись в машине).
• Обновление в одну кнопку и ярлык на рабочем столе при первом запуске.
• Английский интерфейс (кнопка EN/RU).
• Светлая и тёмная тема (по умолчанию — как в Windows).

КАК ПОЛЬЗОВАТЬСЯ
1. Распакуйте архив и запустите VELO_FIX.exe.
2. Перетащите в окно один или несколько .fit (и GPX маршрута, если есть).
3. Справа — сводка и список исправлений; нажмите на исправление, чтобы увидеть его
   на карте. «Исправлено / Исходник» сверху — трек после и до.
4. «Сохранить FIT» — файл для Strava. Стрелка ▾ — другие форматы, сохранение всех
   тренировок и выбор постоянной папки.
5. В Strava: удалите исходную тренировку, затем «+» → «Загрузить действие» → «Файл».
Подробно — кнопка «?» в программе (там же максимальный пульс, FTP и вес).

Если Windows пишет «Система Windows защитила ваш компьютер» — «Подробнее» →
«Выполнить в любом случае» (программа не подписана платным сертификатом).
Если exe не запускается — откройте VELO_FIX.html в Edge или Chrome.

ТРЕБОВАНИЯ
Windows 10/11 (64-бит), Microsoft Edge или Google Chrome. Установка и права
администратора не нужны. Интернет нужен только для подложки карты и проверки
обновлений (раз в 6 часов запрос к GitHub, без ваших данных).

КОНФИДЕНЦИАЛЬНОСТЬ
Файлы обрабатываются только на вашем компьютере. Окно открывается через локальный
адрес http://127.0.0.1:47815 (наружу не виден). Фрагменты карты загружаются с
OpenStreetMap / Esri. Данные программы — в папке %LOCALAPPDATA%\VeloFix.

ИСТОРИЯ ВЕРСИЙ
2.9.1 — если поездка начинается без GPS, в «Дорисовать участок» первый щелчок ставит
        старт A (зелёная точка, её можно перетащить), дальше рисуете до B; карта сразу
        показывает округу, где мог быть старт.
2.9.0 — редактор трека: «К дороге» и «Весь трек к дорогам», выделение протяжкой на карте
        и графике, кисть с видимым радиусом (Shift+колесо, [ ]), ластик, повтор (Ctrl+Y)
        и горячие клавиши, поиск подозрительных мест с исправлением в один клик, точки
        изгиба двойным кликом, длина трека против датчика, пробел — показать исходный трек.
2.8.0 — длинные заезды (24 часа, многодневки) больше не падают при сохранении; одиночные
        записи без дистанции не отключают исправление одометра; поддержка 64-битных полей
        и сжатых меток времени новых устройств; при склейке не теряется первая запись
        второго файла; подсказка склеить части одного заезда; автообновление проверяет
        контрольную сумму SHA-256 архива.
2.1.0 — выбор «Участки без GPS: прямой / пусто» в блоке исправлений; обрезка и разделение
        тренировки, подсказка обрезать поездку на транспорте; уведомление о новой версии;
        карта приближается по реальным точкам GPS. Лицензия MIT.
2.0.1 — участки без GPS, заполненные прямой, рисуются отдельным пунктиром; восстановленные по GPX — штрихом.
2.0.0 — новый интерфейс (светлая/тёмная тема, оранжевый акцент), раскраска трека по
        скорости/пульсу/мощности, пакетная обработка, склейка FIT, сводка и зоны
        пульса/мощности, PNG карты, статистика отрезка, показ исправлений на карте.
1.5.0 — карта с подложкой и профиль. 1.4.0 — выбор папки. 1.1.0 — фантомное движение.

ENGLISH
VELO FIX fixes FIT files from bike computers: phantom speeds, odometer and GPS jumps,
GPS gaps (restored from a route GPX), heart-rate and power spikes; trims, splits and
merges rides; exports FIT, GPX, TCX and a before/after report. Unpack the archive and
run VELO_FIX.exe; switch the language with the EN/RU button. Everything runs locally.
